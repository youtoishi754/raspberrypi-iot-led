# SDカードの認識不良

## 発生した問題

Raspberry Pi 4で使用していたSDカードが正常に認識されなくなった。

Raspberry Pi起動時にエラーが発生し、PC側からSDカードを確認したところ、認識時に発熱する状態となった。

また、SDカードのフォーマットも正常に行えない状態だった。

## 原因の仮説

以下の可能性を考えた。

* SDカード自体の故障
* ファイルシステムの破損
* Raspberry Piへの電源供給不足
* 電源供給の不安定さ
* USBケーブルによる電圧降下

特に、Raspberry Pi 4への電源供給に使用していたUSBケーブルを延長していたため、ケーブルによる電圧降下や電源供給の不安定さがSDカードの異常に影響した可能性を考えた。

## 原因の調査・切り分け

### SDカードの状態確認

PCにSDカードを接続し、認識状態を確認した。

* SDカードが正常に認識されない
* 認識時に発熱する
* フォーマットが正常に行えない

これらの状態から、SDカード自体に問題が発生している可能性を考えた。

### ファイルシステム破損の可能性

Raspberry Piの起動時にSDカード関連のエラーが発生していたため、ファイルシステムの破損も原因の候補として検討した。

### 電源供給の確認

Raspberry Pi 4にはUSBケーブルを使用して電源を供給しており、ケーブルを延長して使用していた。

そのため、ケーブルによる電圧降下や電源供給の不安定さが発生している可能性を検討した。

そこで、Raspberry Piに付属している電源ケーブルを使用して電源供給環境を変更した。

付属の電源ケーブルを使用したところ、電源供給が安定した。

ただし、電源供給の不安定さがSDカード故障の直接的な原因であることまでは確認できていないため、原因として断定せず、可能性の一つとして扱った。

## 対応

問題が発生したSDカードを継続して使用することが難しい状態だったため、新しいSDカードを用意した。

新しいSDカードにRaspberry Piの環境を再構築した。

また、電源供給については、使用していた延長ケーブルを見直し、Raspberry Piに付属している電源ケーブルを使用した。

その結果、電源供給が安定した。

## 動作確認

新しいSDカードに環境を再構築した後、GitHubから本プロジェクトを取得できることを確認した。

```bash
git clone git@github.com:youtoishi754/raspberrypi-iot-led.git
```

その後、Raspberry Pi上でプロジェクトを動作させ、LEDが正常に点滅することを確認した。

## 学んだこと

Raspberry Piのような組み込み機器では、プログラムだけでなく、以下のようなハードウェア側の要因も含めて問題を切り分ける必要があることを学んだ。

* 電源
* USBケーブル
* SDカード
* ファイルシステム
* GPIOなどの周辺機器

特に、電源供給環境を変更することで状態が変化することを確認し、電源・ケーブルもトラブルシューティングの対象として確認する必要があると学んだ。

また、原因を一つに決めつけるのではなく、複数の可能性を挙げて一つずつ確認し、SDカードの交換なども含めて切り分けることが重要だと学んだ。
